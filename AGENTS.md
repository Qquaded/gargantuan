# Gargantuan's LLM Policy

Gargantuan is a pro-human project of passion.

Gargantuan is by-and-large made for, and made by the collective Roblox
community. No singular AI will get to take authorship of this project. This is
a collective project where real humans brings their best effort to create a new
home for Roblox games.

This policy outlines how Gargantuan does (and does not) permit Large Language
Models (LLMs) and generative AI in contributions.

## Boundaries

To protect the creative integrity and craftsmanship of Gargantuan, the following
boundaries apply to all contributions across Team Fireworks repositories:

- Generative AI MUST NOT be used to create or assist with artwork, textures, 3D
  models, sound design, writing, or documentation beyond naming things.
- AI MUST NOT be used to make structural, architectural, or core design
  decisions for Gargantuan.
- AI tools are STRICTLY assistants for the developer workflow (ie. looking up
  about the code syntax, local software tooling as used in the Roblox,
  ecosystem). AI are not co-creators.

## Code contributions

We recognize that many members of the Roblox community rely on AI-assisted
developer tooling, especially when learning systems programming like C++ and
SDL3. While we allow AI as a learning aid, you are responsible for any code
submitted to Gargantuan.

- You are 100% responsible for every line of code, comment, and commit in any
  pull request.
- You must be able to explain, justify, and maintain any code you submit during
  code review. You may not blame AI for bad architecture, hidden bugs, or poor
  logic.
- AI must not be used in an undirected capacity for coding ('vibecoding'). All
  architectural and implementation design must be done by hand.

## Quality over quantity

Unlike other projects, Gargantuan is in no rush. Gargantuan is not a project of
efficiency, but of care and attention, and that's a core proposition of the
engine. Current-day AI tools require serious coaxing to prioritise the same.

We don't want to sacrifice these details on the altar of productivity. Even when
it makes more business sense to move on to the next feature, or to leave
something underpolished, we should ignore the common wisdom and work on it
anyway.

We expect our contributors to apply the same care and attention to every
contribution.

## Ethics

Team Fireworks and godmothersfire do not support or endorse the unethical
practices of major AI vendors. This AI policy is an exemption specific to
Gargantuan for it's unique position in the Roblox community.
